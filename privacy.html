Privacy Policy

Last updated: October 2026

Gym Tracker is a personal fitness tracking application. This policy describes how the application handles data.

1. Personal Use Only

This application is operated solely for personal use by its developer. It is not a commercial product and has no registered users other than the developer.

2. Data Collected

The application stores only the data the user enters themselves:

  • Workout logs — exercises, sets, reps, weights, and timing
  • Session templates and exercise library selections
  • Manually entered daily metrics — recovery, sleep, and strain

3. How Data Is Stored

All data is stored in the user's own browser (localStorage) and, when the user signs in, optionally synced to a private Firebase Firestore database accessible only by that account owner. No data is stored on any third-party server controlled by this application.

4. Data Sharing

No data is shared with any third party. No analytics, advertising, or tracking services are used. No data is sold, rented, or disclosed to any external entity.

5. Authentication

Optional sign-in is provided through Google via Firebase Authentication, used solely to sync the user's own data across their own devices. No profile information is used for any other purpose.

6. Data Retention

Data persists in the browser until the user manually clears it. When sync is enabled, deleting a workout log in the application, or using "Clear all data" while signed in, also removes it from the synced database.

7. Contact

For any questions about this policy, contact the developer at: github.com/aturpin88/gym-tracker
